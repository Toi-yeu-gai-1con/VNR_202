# Zone Identity 31–42 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every playable zone visually, mechanically, and narratively distinct, with original landmark art and persistent post-mission presentation.

**Architecture:** Add a `ZONE_PROFILES` configuration beside existing level data in `game.js`. Rendering, ambient audio, and dialogue use profile helpers while `state.completedZones` remains the source of persistence. Four original transparent PNGs are registered in the environment sprite registry.

**Tech Stack:** Vanilla JavaScript, Canvas 2D, HTML audio, Node assertion scripts, Playwright, imagegen-generated PNG assets.

## Global Constraints

- Preserve the existing Canvas 2D runtime and save compatibility.
- Use original game-specific landmark art only; introduce no third-party assets.
- Failed or browser-blocked audio cannot block gameplay.
- Use `apply_patch` for source and test edits.

  zone1: { verb: "Bảo vệ dân", landmark: "stormShelterBeacon", weather: "storm" },
