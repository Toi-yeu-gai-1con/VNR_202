# Cục Lưu Trữ Niên Tuyến (CLTNT)

Original retro-bureaucratic time-archive assets for VNR202. The visual language is deliberately its own: 1970s Vietnamese archival office cues, brutalist concrete, warm mustard/brown furniture, green CRTs, and orange/blue temporal hardware.

The character is **Analyst M-90**, an exhausted field clerk and possible guide. He carries a clipboard and coffee while his belt holds a Chronicle Pad, highlighter, and compact enforcement baton. Dialogue can use KPI/report humor, but the art contains no readable brand text.
